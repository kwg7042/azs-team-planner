# EXAONE 로컬 프록시 (팀플래너용)

팀플래너의 EXAONE 기능(이슈 분석·특허 모션)은 브라우저에서 EXAONE을 직접 부르면 막히거나(CORS) API 키가 노출됩니다.
이 프록시를 **각자 PC에서** 켜 두면 팀플래너가 `http://localhost:8787`로 요청하고, 프록시가 내 API 키를 붙여 EXAONE에 전달합니다.

## 사용법 (Windows)
1. `exaone_proxy.py`와 `EXAONE_proxy_start.bat`을 같은 폴더에 내려받습니다. Python 3이 필요하며, 추가로 설치할 패키지는 없습니다.
2. `EXAONE_proxy_start.bat`을 더블클릭합니다.
3. 처음 한 번만 API 키를 입력합니다. 키는 같은 폴더의 `exaone_proxy_config.json`에만 저장됩니다.
4. 창을 켜 둔 채로 팀플래너 > AI 설정 > EXAONE > **연결 테스트**를 눌러 확인합니다.
   - 브라우저가 "이 기기의 다른 앱·서비스 접근(로컬 네트워크)" 권한을 물으면 **허용**을 누릅니다.

## 문제 해결
| 증상 | 원인 / 조치 |
|---|---|
| 프록시 응답 없음 | 프록시 창이 꺼져 있습니다. bat을 다시 실행하세요. |
| 401 | API 키가 틀렸습니다. `EXAONE_proxy_start.bat --reset`을 실행해 다시 입력하세요. |
| 403 Forbidden origin | 예전 프록시입니다. 이 폴더의 최신 프록시로 실행하세요. |
| 502 | 프록시는 켜졌지만 EXAONE 서버에 닿지 않습니다. 회사망이나 인터넷 연결을 확인하세요. |
| 포트 8787을 열 수 없음 | 이미 프록시 창이 켜져 있습니다. 켜진 창을 그대로 쓰면 됩니다. |

옵션:
- `--port 8787`: 포트를 바꿉니다. 바꾼 경우 팀플래너 AI 설정의 프록시 URL도 맞춰야 합니다.
- 환경변수 `EXAONE_API_KEY`, `EXAONE_BASE_URL`, `EXAONE_PROXY_TIMEOUT`(초, 기본 900)을 쓸 수 있습니다.
